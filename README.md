# Object-Oriented Programming in Java — Lab Solutions

This repo holds my solutions to all eleven labs from the OOP course. Each lab lives in its own IntelliJ IDEA project so you can open and run them independently without touching anything else.

## Lab overview

| Folder | Topic |
|---|---|
| OOPLab1  | Classes and Objects |
| OOPLab2  | Constructors, `this`, and Static Members |
| OOPLab3  | Encapsulation and Access Modifiers |
| OOPLab4  | Inheritance |
| OOPLab5  | Polymorphism |
| OOPLab6  | Abstraction, Abstract Classes, and Interfaces |
| OOPLab7  | Exception Handling |
| OOPLab8  | Generics and the Collections Framework |
| OOPLab9  | Nested Types, Enums, Records, and the Object Contract |
| OOPLab10 | File I/O, Lambdas, and Streams |
| OOPLab11 | Design Patterns and the Mini-Project (Library Management System) |

## How to open a lab

1. In IntelliJ IDEA, go to **File > Open** and select the lab folder (e.g. `OOPLab3`).
2. If prompted for a Project SDK, pick any JDK 17 or newer.
3. Navigate to the class you want to run and click the green arrow next to its `main` method.

Each lab folder has its own `README.md` with a list of all the classes and what they do, plus a `sample_output.txt` showing the expected output.
